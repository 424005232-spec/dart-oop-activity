# PC16 - Week 10: Enhanced Object-Oriented Programming (OOP) in Dart

This repository contains my individual submission for **Week 10: Object-Oriented Programming in Dart (Part 2)** under the PC16 Mobile Development course.

## Overview
The application is a console-based program written in Dart that demonstrates key Object-Oriented Programming concepts:
- **Base Class & Inheritance:** `Car` and `Motorcycle` extend the `Vehicle` base class.
- **Polymorphism:** Method overriding used on `startEngine()` to provide unique behaviors for each vehicle.
- **Abstract Class / Interface:** `Maintenance` enforces a `checkOil()` method contract for implementing classes.
- **Mixin:** `MusicPlayer` adds modular functionality (`playMusic()`) to the `Car` class using the `with` keyword.

## How to Run
1. Open [DartPad](https://dartpad.dev/).
2. Copy and paste the code from `main.dart` into DartPad.
3. Click **Run** to view the output in the console.
