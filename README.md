# PC16 - Week 10: OOP Activity

This is my individual submission for Week 10 Object-Oriented Programming in Dart.

## Overview
This console program demonstrates basic OOP principles:
- **Inheritance:** `Car` and `Motorcycle` extend the `Vehicle` base class.
- **Polymorphism:** The `start()` method is overridden in both classes.
- **Abstract Class:** `ServiceCheck` is implemented by the derived classes.
- **Mixin:** `RadioPlayer` is added to the `Car` class using the `with` keyword.

## How to Run
1. Open [DartPad](https://dartpad.dev/).
2. Paste the code from `main.dart`.
3. Click Run.
